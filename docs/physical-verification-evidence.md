# Target integration and physical evidence

This ledger contains the detailed target-integration and physical evidence that
is intentionally kept out of the concise matrix in
[requirements.md](requirements.md). Each matrix status links to exactly one row
below.

Status meanings are the same as in the matrix. A `Partial` entry records both
the reviewed physical behavior and the narrower unresolved boundary. A mock or
target-build result never substitutes for electrical, media, RF, sensor, or
endurance evidence.

Pending rows are grouped by the equipment and safety boundary needed to close
them in [physical-verification-backlog.md](physical-verification-backlog.md).
